Projeto desenvolvido para praticar desenvolvimento web e GitFlow.

## Sobre o projeto

Esse repositório é de modelo teste para a criação de repositórios git via github onde serão implementados conceitos recém aprendidos de

de programação e controle de versão utilizando Git.

## Tecnologias utilizadas

- html

- css

- javascript

- Git

- GitHub

## Estrutura de branches

- `main`: versão estável do projeto.

- `develop`: desenvolvimento contínuo.

- `feature/`: desenvolvimento de novas funcionalidades.

- `hotfix/`: correções urgentes.

## Como executar

supondo que fosse um modelo readme para um app em produção, apenas isso passaria como aceito?

1. Instale o Vscode.

2. Baixe ou clone o repositório.

3. Execute o arquivo principal.
